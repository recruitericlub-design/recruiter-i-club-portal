# UI/UX И ДИЗАЙН-СПЕЦИФИКАЦИЯ ПЛАТФОРМЫ RECRUITER I CLUB (СТАНДАРТЫ 2026 ГОДА)

**Профессиональное руководство по визуальному инжинирингу, интерактивным механикам, анимации и проектированию высокотехнологичного B2B/B2C интерфейса, полностью защищенного от эффекта «шаблонного AI-дизайна».**

## ВВЕДЕНИЕ: ПОЧЕМУ ТИПИЧНЫЙ «ИИ-ДИЗАЙН» — ЭТО СМЕРТЬ ДЛЯ B2B-КОНВЕРСИИ

Большинство сайтов в 2025–2026 годах выглядят одинаково из-за массового использования генеративных ИИ-инструментов. Такой псевдо-дизайн («AI-generated garbage») легко распознать по следующим признакам:
*   **Глянцевые, стерильные 3D-иллюстрации** (пластиковые «глиняные» руки, летающие трехмерные папочки, шестеренки, изометрические кубики).
*   **Слишком яркие, «ядовитые» градиенты** без логики и структуры, используемые просто для заполнения пустоты.
*   **Отсутствие текстуры и физики** — интерфейсы кажутся плоскими, «дешевыми» и нематериальными.
*   **Шаблонная сетка** без контраста, скучные стоковые фотографии улыбающихся людей, не имеющие отношения к реальному производству.

**Философия дизайна Recruiter I Club (I CLUB):**  
Мы проектируем авторитетную, дорогую и технологически продвинутую B2B/B2C платформу в стиле **Tactile Brutalism (Тактильный брутализм)** в сочетании с **Liquid Glass (Жидкое стекло)**. Наш интерфейс должен выглядеть как кастомный цифровой терминал управления глобальными ресурсами. Он физически ощущается тяжелым, надежным, глубоким и безупречно точным.

## 1. ЦВЕТОВАЯ ПАЛИТРА И ТЕКСТУРИРОВАНИЕ (DESIGN TOKENS)

Интерфейс работает по умолчанию в **системной темной теме (Dark Mode)**, которая символизирует премиальность, конфиденциальность и снижает нагрузку на глаза при долгой работе в личном кабинете.

### 1.1. Цветовая сетка (Hex-коды и применение)

```
[  #05070A  ] ──► Базовый холст (Deep Obsidian) — космический глубокий черный.
[  #0E1118  ] ──► Подложка Bento-панелей (Dark Slate) — матовый графит.
[  #1A1F2C  ] ──► Границы, сетки, неактивные элементы (Steel Border).
[  #00E5FF  ] ──► Первичный акцент (Electric Cyan) — интерактивные элементы, фокус.
[  #10B981  ] ──► Статус «Успешно» / «На смене» (Emerald Green).
[  #F59E0B  ] ──► Статус «Транзит» / «В пути» (Amber Gold).
[  #F9FAFB  ] ──► Основной текст (Pure White/Silver).
[  #9CA3AF  ] ──► Вторичный текст, подписи (Muted Gray).
```

### 1.2. Физическое текстурирование: Шумовой SVG-фильтр (SVG Noise Overlay)
Чтобы убрать эффект «цифрового пластика», на весь сайт накладывается тончайший, едва заметный слой аналогового шума. Он создает ощущение дорогой матовой бумаги или шлифованного металла.

**Код для интеграции в глобальный CSS/Tailwind:**
```css
.noise-overlay {
  position: fixed;
  top: 0;
  left: 0;
  width: 100vw;
  height: 100vh;
  content: "";
  opacity: 0.025; /* Едва заметный порог */
  pointer-events: none;
  z-index: 9999;
  background-image: url("data:image/svg+xml,%3Csvg viewBox='0 0 200 200' xmlns='http://www.w3.org/2000/svg'%3E%3Cfilter id='noiseFilter'%3E%3CfeTurbulence type='fractalNoise' baseFrequency='0.8' numOctaves='3' stitchTiles='stitch'/%3E%3C/filter%3E%3Crect width='100%25' height='100%25' filter='url(%23noiseFilter)'/%3E%3C/svg%3E");
}
```

## 2. ТИПОГРАФИКА: СМЕЛЫЙ РЕДАКЦИОННЫЙ КОНТРАСТ

Шрифт — это главный носитель характера бренда. Мы используем три жестких шрифтовых семейства для идеального разделения информации.

```
       [ Clash Display ]               [ General Sans ]              [ JetBrains Mono ]
    Акцентные H1/H2 заголовки        B2B контент, лонгриды         Данные, телеметрия,
  Геометрический нео-гротеск.       Предельно чистый гротеск.      CRM-статусы, калькулятор.
```

### 2.1. Использование шрифтовых семейств

1.  **Заголовки (H1, H2, Bento-титры):** **Clash Display** (или кастомный *PP Neue Montreal / Neue Plak*). Тяжелый геометрический нео-гротеск с закрытым аппретурным рисунком. Он выглядит строго, премиально и монументально.
2.  **Текстовые блоки, описания услуг, лонгриды:** **General Sans** (или *Satoshi / Inter*). Высокочитаемый швейцарский гротеск с нейтральным характером.
3.  **Метрики, цифры калькулятора, CRM-логистические статусы, тайминги:** **JetBrains Mono** (или *SF Mono*). Моноширинный шрифт, который мгновенно превращает любые массивы данных в эстетичный, кристально понятный технологичный лог-отчет.

### 3.1. Технические спецификации Bento-плиток для верстки:
*   **Скругление углов (Border Radius):** Жесткие `rounded-xl` (12px) или `rounded-2xl` (16px). Никаких огромных овальных скруглений из «эры мобильных приложений». Мы делаем солидный десктопный продукт.
*   **Свечение границ (Border Trail Effect):** Границы Bento-плиток по умолчанию темные (`border-[#1A1F2C]`). При движении курсора по экрану, границы плиток должны подсвечиваться мягким градиентомElectric Cyan в точке, ближайшей к мышке.
*   **Глубина (Glassmorphism):** Задний фон панелей имеет полупрозрачность и матовый эффект: `background: rgba(14, 17, 24, 0.75); backdrop-filter: blur(12px);`.

## 4. ИНТЕРАКТИВНЫЕ ГРАФИЧЕСКИЕ ЭЛЕМЕНТЫ И 3D (WEBGPU + THREE.JS)

Сайт должен вовлекать пользователя физическим взаимодействием с графикой.

### 4.1. Первый экран (Hero Section): Интерактивная 3D-сеть «Транзит Талантов»
На первом экране интегрируется 3D-сцена на **Three.js** с рендерингом через **WebGPU за замовчуванням** (с авто-фолбеком на WebGL для старых систем).
*   **Визуальный концепт:** Абстрактное созвездие из 500 светящихся микро-частиц (вертексов), соединенных тончайшими линиями. Это символизирует глобальную сорсинговую сеть **Recruiter I Club**.
*   **Интерактивная физика:**
    *   *Магнитное притяжение:* При перемещении курсора по экрану частицы в радиусе 150px начинают плавно устремляться к курсору, создавая вихревое свечение. При быстром движении мыши частицы слегка разлетаются в стороны по законам инерции.
    *   *Скролл-динамика (GSAP ScrollTrigger):* По мере скроллинга страницы вниз, 3D-камера плавно пролетает сквозь эту сеть по оси Z. Частицы масштабируются, пролетая мимо экрана, что создает невероятную кинематографичную глубину.

### 4.2. Интерактивный B2B-виджет «LIVE CRM TELEMETRY»
Вместо статичной картинки «как мы работаем», на главной странице размещается интерактивный модуль телеметрии, подключенный к API базы данных CRM.

**Механика взаимодействия:**
1.  **Интерактивная 2D-карта транзита:** Минималистичная векторная карта Азии и Европы в темных тонах. По ней плавно движутся светящиеся точки-импульсы (группы кандидатов) по реальным маршрутам бренда: *Дели/Ташкент ➔ Кишинев ➔ Одесса ➔ Киев/Львов*.
2.  **Панель событий (Event Log):** Справа от карты выводится моноширинный лог реального времени (JetBrains Mono). Пользователь может кликнуть на любую запись, чтобы развернуть детали:
    *   `[2026-09-07 14:15] Group UZ-12 (Tashkent): Visa D-04 Issued. Transition ETA: 48h.`
    *   `[2026-09-07 15:30] Group IN-09 (New Delhi): Customs border cleared (Palanka, UA).`
3.  **Локализация на стороне фронтенда (Защита от штрафов):** Все статусы из CRM, написанные менеджерами на русском или английском, сайт автоматически переводит по словарю-компликатору на чистый украинский язык перед выводом на экран.

### 4.3. Интерактивные карточки «Pre-Vetted Pool» (Каталог кандидатов)
В B2B-разделе выводится сетка Bento-карточек реальных кандидатов, находящихся на финальном этапе скрининга в Азии.

**Механика взаимодействия:**
1.  **Эффект Hover Zoom & Play:** Карточка кандидата содержит его профессиональную студийную фотографию в ч/б. При наведении на нее мышки:
    *   Изображение плавно окрашивается в цветной спектр и увеличивается на 3% за 400мс.
    *   Фотография плавно растворяется, и прямо внутри Bento-ячейки начинает беззвучно проигрываться видеовизитка кандидата (с наложенным водяным знаком **Recruiter I Club** и затертыми метаданными для защиты от обхода платформы).
2.  **Интерактивные барометры квалификации:** При наведении на карточку раскрываются радарные диаграммы (Radar Charts) или шкалы с оценками физических тестов кандидата. Пользователь может кликнуть на шкалу, чтобы детально прочитать регламент теста, проводившегося руководством компании в Азии.

## 5. ИНТЕРАКТИВНЫЕ B2C И B2B ИНСТРУМЕНТЫ (КВИЗЫ И КАЛЬКУЛЯТОРЫ)

### 5.1. B2C Квиз-виджет для кандидатов («Шукаєш роботу?»)
Красивый интерактивный инструмент для привлечения бесплатных кандидатов через сайт.
*   **Стиль:** Компактная Bento-ячейка на главном экране или выделенный полноэкранный стек на странице B2C.
*   **Пошаговая физика (Stepper):** 
    *   *Шаг 1:* Выбор страны (Индия, Непал, Бангладеш, Узбекистан) с красивой 3D-анимацией флага при клике.
    *   *Шаг 2:* Выбор специальности (Сварщик, Швея, Строитель, Разнорабочий). При клике плитка специальности сжимается на 5% (эффект пружины) и издает мягкое свечение.
    *   *Шаг 3 (Тактильный Drop-zone для CV):* Область загрузки резюме и видеоприветствия оформлена в виде гравитационной зоны. При перетаскивании файла на экран, зона начинает мягко пульсировать синим неоном. При «бросании» файла происходит физически корректная анимация падения документа в ячейку с легким отскоком и заменой иконки на зеленую галочку.
*   **Сортировка трафика:** Бэкенд автоматически маркирует полученные данные тегом `type: candidate` и направляет их в изолированную таблицу `Contact` CRM-системы со статусом `new_applicant`, полностью исключая ручной труд рекрутеров и защищая базу клиентов от мусора.

### 5.2. Динамический B2B Калькулятор упущенной выгоды и окупаемости
Вместо скучных статичных таблиц этот блок работает как финансовый симулятор.
*   **Ползунки управления (Custom Ranges):** Собственник или CFO может двигать интерактивные бегунки ( sliders):
    *   «Річний оборот компанії» (от 1 млн до 500 млн грн).
    *   «Кількість пустуючих вакансій» (от 1 до 100 человек).
    *   «Дні простою обладнання» (от 10 до 180 дней).
*   **Анимация результатов:** При передвижении слайдеров цифры дневных потерь и упущенной выгоды (JetBrains Mono) пересчитываются мгновенно с эффектом прокрутки барабана (CountUp.js).
*   **Живая Canvas-диаграмма:** В режиме реального времени на экране перерисовывается график потерь бюджета. При достижении критической зоны график окрашивается в тревожный красный цвет, а рядом плавно выезжает кнопка-триггер: **«Перекрити втрати з Recruiter I Club»**, ведущая на форму заказа.

## 6. АНИМАЦИОННЫЙ РЕГЛАМЕНТ (MOTION DESIGN & PERFORMANCE)

Анимация должна быть незаметной, но физически естественной. Мы полностью отказываемся от линейной анимации (linear easing) в пользу реалистичной физики движения.

### 6.1. Спецификации переходов и Изинг-кривые
Все минорные анимации (hover-эффекты кнопок, появление полей ввода) жестко стандартизируются по времени и физическим кривым:
*   **Transition Duration:** строго **250мс** для микро-взаимодействий, **450мс** — для открытия Drawer-панелей и перегруппировки Bento Grid.
*   **Easing Curve (Пружина):** `cubic-bezier(0.25, 1, 0.5, 1)` (аут-изинг повышенной плавности, имитирующий физическое трение).

### 6.2. Магнитный эффект кнопок (Magnetic Buttons)
Все конверсионные кнопки (CTA) на сайте снабжаются физическим эффектом магнитного притяжения. При приближении курсора мыши к кнопке на расстояние ближе 35px:
*   Кнопка начинает плавно притягиваться к курсору по осям X и Y (смещение до 12px).
*   Внутри кнопки активируется радиальный градиент подсветки, который следует точно за точкой входа курсора.
*   При выходе курсора за пределы радиуса, кнопка возвращается в исходное состояние с мягким затухающим колебанием (Spring Animation).

Чтобы ваш сайт выглядел как кастомный цифровой шедевр ручной работы, дизайнеру ставится ультимативное табу на следующие элементы:

1.  **Категорическое ТАБУ на стоковое 3D:** Никаких трехмерных кубиков, пластиковых человечков или летающих иконок из бесплатных библиотек. За любые попытки внедрить стоковые 3D-иллюстрации разработчик штрафуется.
2.  **Замена графики на реальный контент:** Все иллюстрации заменяются на:
    *   Интерактивные 3D-абстракции на Three.js (реальный код вместо картинок).
    *   Качественные, кинематографичные ч/б видеофрагменты практического тестирования соискателей в Азии (сварка, работа за швейным станком), интегрированные прямо в bento-блоки.
    *   Реальные исторические архивные фотоматериалы компании с 2019 года (офисы, поездки руководства в Азию, беженцы, которым бренд помог найти работу в Европе в 2022 году).
3.  **Использование псевдокода как графики:** В качестве декоративных элементов фона можно использовать полупрозрачные технические логи, схемы баз данных Prisma ORM или фрагменты реальных юридических договоров I CLUB, набранных шрифтом JetBrains Mono. Это создает мощное ощущение честности, глубины и реального ИТ-продукта.

## 8. КРИТЕРИИ СКОРОСТИ И ПРОИЗВОДИТЕЛЬНОСТИ (SLA FOR DEV)

*   **Skeleton Screens с Shimmer-эффектом:** При загрузке личного кабинета, графиков или каталога кандидатов запрещено показывать пустые белые экраны или стандартные «колесики» загрузки. На экране мгновенно появляются серые Bento-структуры, по которым слева направо плавно проходит анимированная волна света. Это снижает воспринимаемое время загрузки на 40%.
*   **Сжатие 3D-сцены:** Все 3D-модели вертексов оптимизируются в формате `.glb` с запеченным освещением. Общая вага сцены для первого экрана не должна превышать **1.5 МБ**.
*   **Показатели LCP (Largest Contentful Paint):** Время рендеринга главного визуального блока на мобильных устройствах не должно превышать **1.8 секунды** для попадания в зеленую зону Google PageSpeed Insights.
